## 2025-08-13 - Metadata Separator Accessibility and Non-interactive Card Cues
**Learning:** Repetitive characters used as visual delimiters in metadata strings (e.g. "·" in "Year · Genre") are read literally by screen readers, creating cognitive noise. Wrapping separators in `aria-hidden="true"` spans resolves this. In dynamic or mapped components, splitting metadata strings and programmatically injecting hidden separators keeps clean content while ensuring accessibility. Additionally, adding `cursor-pointer` to non-interactive container elements misleads keyboard and assistive technology users into expecting interactive behavior; interaction must be confined strictly to semantic focal elements like links and buttons.
**Action:** Implement a programmatic `.split(" · ")` map pattern to isolate and hide decorative metadata delimiters, and avoid general pointer hover styling on non-interactive containers containing interactive children.
