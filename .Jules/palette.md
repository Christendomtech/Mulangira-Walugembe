# Palette's Journal - Critical Learnings

## 2025-05-15 - Initial Audit
**Learning:** The portfolio lacks basic accessibility features like a skip-to-content link and descriptive ARIA labels for repetitive "Explore" and "Request a copy" links. The main content is not wrapped in a semantic <main> tag.
**Action:** Implement a skip-to-content link and improve link accessibility with descriptive ARIA labels and semantic HTML.
