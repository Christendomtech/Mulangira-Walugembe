## 2025-05-18 - Skip Link, Semantic Main Landmark, and ARIA Micro-UX Enhancements
**Learning:** In single-page portfolio layouts with fixed header navigation, keyboard-only users need a dedicated skip-to-content bypass link and semantic `<main>` landmark element to bypass global navigation quickly. In addition, dynamic metadata text strings with decorative dot separators (e.g. "Year · Genre") and ambiguous repetitive links ("Explore", "Request a copy") degrade screen reader usability if visual decorative dots are not hidden via `aria-hidden="true"` and links lack explicit `aria-label` context.
**Action:** Always include a skip-to-content bypass link targeting `#main-content`, wrap primary page content in `<main id="main-content" tabIndex={-1}>`, hide decorative dot separators, and annotate action links with contextual `aria-label`s.
