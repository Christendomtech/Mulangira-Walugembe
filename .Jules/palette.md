## 2025-08-08 - Keyboard Bypass and Metadata Separation accessibility standardizing
**Learning:** Skip-to-content keyboard bypass links must focus a container with a valid ID and `tabIndex={-1}` outside global navigation and footers to ensure screen readers skip straight to primary content. Separators in metadata strings (e.g. dots or slashes) are vocalized as punctuation by screen readers unless programmatically split and wrapped in `aria-hidden="true"` spans.
**Action:** When working on layout-heavy landing pages, always introduce a skip link at the top of the DOM targeting `#main-content`, wrap all main sections in a `<main id="main-content" tabIndex={-1} className="outline-none">` element, and split metadata strings programmatically using React.Fragment to isolate punctuation separators.
