# Palette's Journal - Prince Edward Walugembe Portfolio

## 2025-05-22 - Skip-to-content Accessibility Pattern
**Learning:** For single-page portfolios with sticky navigation, keyboard accessibility is significantly improved by a skip-to-content link targeting a semantic `<main>` tag with `tabIndex={-1}`.
**Action:** Implement `.skip-to-content` utility in CSS and add the bypass link as the first child of the body/root container in all future projects using this design system.
