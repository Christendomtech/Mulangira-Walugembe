## 2025-05-14 - [Keyboard Accessibility & Screen Reader Context]
**Learning:** High-end portfolios often focus on visual aesthetics but overlook keyboard navigation (focus states, skip links) and screen reader context for repetitive links. Accessibility enhancements can be implemented as subtle, non-intrusive improvements that significantly benefit a subset of users without affecting the visual design for others.
**Action:** Implement "Skip to Content" links, visible focus states, and descriptive ARIA labels for links that rely on visual context.
