## 2025-05-15 - Accessibility Foundations for Portfolios
**Learning:** Foundational accessibility features like "Skip to content" links, semantic <main> landmarks, and descriptive aria-labels for repetitive links significantly improve the UX for keyboard and screen reader users without impacting visual design. Programmatically handling separators in metadata strings (e.g., Year · Genre) using aria-hidden prevents "middle dot" from being read aloud.
**Action:** Always implement a skip-link and semantic landmarks on new pages. Ensure all icon-only or repetitive links have descriptive labels.
