## 2025-05-18 - Semantic Bypass Link & Dynamic ARIA Labels in Single-Page Portfolios
**Learning:** In minimalist portfolio pages with fixed navigation bars and repetitive section call-to-actions ("Explore", "Request a copy"), keyboard users face navigation fatigue and screen reader users hear duplicate context-free link labels. Standardizing explicit `aria-label`s with dynamic context and adding a skip link with smooth-scroll padding significantly enhances keyboard and assistive technology usability.
**Action:** Always pair fixed header navigation with a high-contrast `.skip-to-content` link that targets `<main id="main-content" tabIndex={-1}>`, apply `scroll-pt-*` to prevent target overlap, and annotate generic repetitive link text with dynamic descriptive ARIA labels (`aria-label={`Explore ${item.title} details`}`).
