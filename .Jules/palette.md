## 2025-05-15 - Accessibility Fundamentals for Portfolio Sites
**Learning:** Implementing "Skip to Content" links and semantic `<main>` tags significantly improves keyboard and screen reader navigation, especially in single-page portfolio layouts with large hero sections. Consistent focus indicators (using `focus-visible`) provide essential visual feedback for keyboard users without compromising the design for mouse users.
**Action:** Always include a "Skip to Content" link and wrap primary content in a `<main>` tag with `tabIndex={-1}` for programmatic focus. Ensure all repetitive links (e.g., "Explore", "Read More") have descriptive `aria-label` attributes for screen readers. Apply `focus-visible:ring` with appropriate `ring-offset` matching the background color to ensure high-contrast focus states.
